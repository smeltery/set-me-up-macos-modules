# 'macports' Module

[![License: PolyForm Shield 1.0.0](https://img.shields.io/badge/License-PolyForm%20Shield%201.0.0-blue.svg)](https://polyformproject.org/licenses/shield/1.0.0)

This repository is designed to be used as a submodule to the [`set-me-up` blueprint](https://github.com/smeltery/set-me-up-blueprint) repository.

⚠️ **Note**: This repository should not be used as a standalone script because it has a dependency on an existing 'set-me-up' configuration already installed on your machine.

## _Why abstract these modules to an external repository?_

Please see the [universal modules documentation](https://github.com/smeltery/set-me-up-universal-modules#why-abstract-these-modules-to-an-external-repository) for more details on this point.
